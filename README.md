Simple player vs computer battleships created with python. It's you versus computer. Who shall sail home to their families?

The game is being rebuilt in Rust as a small Windows game with a C64/Amiga look, playable with mouse and keyboard. Build it with `cargo build --release`; the result is the single file `target\release\laivanupotus.exe`. It opens a launcher where you pick the game; `Esc` in a game returns to the launcher, and `Esc` in the launcher quits.
